# คลังยา รพ.สต.บ้านทรายขาว

ระบบคลังยาและเวชภัณฑ์สำหรับ รพ.สต.บ้านทรายขาว ทำงานเป็นเว็บแอปบน GitHub Pages เก็บข้อมูลในเบราว์เซอร์ (localStorage)

## ใช้งาน

เปิดเว็บ: https://pongvitsam.github.io/DrugInventorySystem/

## ฟีเจอร์

- แดชบอร์ดมูลค่าคงคลัง (คลังหลัก + ตู้ข้างนอก)
- ทะเบียนยาและเวชภัณฑ์
- รับเข้าจากใบเสร็จ/ใบอนุมัติเบิก (รองรับจำนวนแบบ `2x100's`)
- เบิกจากคลังหลักไปตู้ข้างนอก
- ตัดจ่าย / ตรวจนับ
- รายงานพิมพ์: แบบฟอร์มเบิกยารายเดือน, รายงานยอดเงิน, ใบเบิกเวชภัณฑ์ไตรมาส
- นำเข้าข้อมูลเริ่มต้นจากไฟล์ Excel เดิม (พ.ค.69 + ไตรมาส)
- ส่งออกข้อมูลสำรอง JSON

## หมายเหตุ

- ข้อมูลอยู่ในเครื่องที่เปิดใช้งาน ควรส่งออกสำรองเป็น JSON เป็นระยะ
- ไฟล์ Google Apps Script เดิมยังอยู่ใน repo แต่ไม่ได้ใช้ deploy แล้ว
